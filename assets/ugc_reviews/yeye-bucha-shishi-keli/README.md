# 爷爷不泡茶「柿柿可利」买家实拍素材库

目标：100 张有明确商业使用授权的真实买家实拍图。

当前合格素材数：0 / 100。

## 入库标准

每张图必须同时满足以下条件，否则不得计数或用于发布：

1. 与「柿柿可利」商品/套餐匹配，能够确认是实际拍摄而非 AI 生成。
2. 权利人对图片有处分权，并明确书面许可本项目用于商业宣传、剪辑/裁切（如需要）和抖音图文发布；仅在抖音或美团公开可见、平台协议授权平台使用，不满足本项。
3. 原图无水印；不通过裁剪、擦除、覆盖方式去除来源水印。
4. 画面中没有真人或可识别面部；没有字幕、评论截图文字、订单/手机号等个人信息。
5. 来源、授权证据、权利人及许可范围登记在 `manifest.csv`。

请将通过授权且完成核验的原图放入 `images/`，以 manifest 的 `asset_id` 命名。授权证据可记录到经许可的合同/授权单文件位置；不要在登记表写入买家不必要的个人信息。没有证据的图片置于库外隔离区，不能计入目标数量。

## 来源说明

不要批量抓取抖音店铺或美团的公开评价图片。公开评价不自动授予商家或本项目下载、复制并用于广告的权利。美团用户服务协议尤其规定内容知识产权归用户/原始权利人，并界定了给美团及关联方的许可范围。应取得图片权利人对本项目的具体授权，或使用品牌/门店自有且权属明确的实拍素材。
