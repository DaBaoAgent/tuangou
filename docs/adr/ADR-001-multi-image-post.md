# ADR-001：图文作品必须使用多张图片

- 日期：2026-10-31
- 状态：已采纳；平台多图上传能力与后续质量流程待重新验收
- 决策人：用户

## 背景

项目原规格把抖音图文设为单张图片：先生成三个候选，再选一张发布。此前确实有过单图测试/发布记录。用户随后反馈，抖音将该单图图文判为违规，并明确要求今后不能再单独发一张图文。

## 决策

从现在起，项目与人工操作流程均禁止提交只有一张图片的图文作品。每篇图文至少使用 2 张图片；候选图片质量审核、素材授权审核均按最终组合中的每张图片执行。若页面、素材或生产流程无法提供至少两张合规图片，则停止，不发布，并保持 dry-run。

该决策是基于当前账号的一次实际反馈形成的保守项目规则，不宣称这是抖音对所有账号、所有发布场景的普遍规则。发布功能仍处于 Phase 0 未通过状态，首次真实发布还需用户明确批准。

## 素材来源与买家评价图片

用户希望为“爷爷不泡茶【柿柿可利】”收集 100 张真实买家实拍图，并要求无水印、无人、无字幕、非 AI 生成。平台上的公开可见不代表获得复制、下载和商业推广权。抖音用户协议要求上传内容为原创或已获授权，并禁止未经许可对平台内容进行抓取或商业使用；美团协议声明用户内容知识产权归用户或原始著作权人，平台取得的授权是给美团及关联方的，且协议限制第三方使用已发布内容。因此，不从公开评价页抓图、不使用爬虫/截屏批量采集、不去除水印。

只有在取得适用于商业宣传/抖音发布的明确书面授权，且授权人有权许可的情况下，才将图片收录到本地素材库。每张素材须登记来源、权利人、许可范围和证据；并核验真实拍摄、商品匹配、无人/无可识别面部、无水印、无字幕文字、非 AI 生成。不能核实的图片拒收，不计入 100 张目标。用户可提供授权素材或促成买家逐张授权。

官方协议参考（核查日期 2026-10-31）：

- [抖音用户服务协议](https://www.douyin.com/draft/douyin_agreement/douyin_agreement_user.html?id=6773906068725565448)：第 10.2、10.3 节涉及上传内容合法授权及授予平台的内容许可；协议另有关于未经许可使用抖音信息内容的限制。
- [美团用户服务协议](https://i.meituan.com/about/mt-agreement)：用户内容的知识产权归用户或原始权利人；平台协议授予美团及关联方权利，并规定第三方权利边界。
- [美团规则中心知识产权声明](https://rules-center.meituan.com/m/detail/guize/69)：明确平台内容的使用限制，并说明用户发布的内容授权给美团；该授权不是本项目的授权。

## 后果与后续工作

- 更新项目需求基线和操作手册，旧单图操作只保留作历史记录。
- 多图 UI 上传、作品预览、发布结果验证需在 Phase 0 后重新验收；未验收前不声称能力已实现。
- 建立素材库登记模板；初始素材数为 0。达到 100 张后再通知用户。
