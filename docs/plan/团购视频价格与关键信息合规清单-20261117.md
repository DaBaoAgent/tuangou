# 团购视频：价格与关键信息能不能出现（合规清单）

调研日期 2026-11-17。依据抖音生活服务规则中心/学习中心公开条文，落成代码可执行的判定口径。
适用对象：本账号（团购带货创作者）发布的短视频，含代码绘制（AIGC）形式。

## 一、结论（三句话）

1. **价格必须出现，而且必须说清楚。** 平台把"价格是否真实、准确、与商详一致"当作合规基线；模糊表述（"100出头""不到一杯奶茶钱""人均不到X"）本身就是违规项。
2. **能不能"突出"价格，取决于两个前提**：数字与 POI 商详当前团购价一致；影响决策的限制条件（配送/门店/时段/加价/预约/人群）与价格同等显著，不能小字弱化。
3. **纯代码/信息图形式的真正风险不在价格，在"真实性"**：达人探店类内容要求真实到店拍摄，且质量分级把"大字报""图文小广告（海报/截图轮播）""素材拼接""云剪辑"列为负向内容。价格写对只是过线，形式决定能不能拿到流量。

## 二、硬性形式要求（形式不达标，内容再好也没用）

| 项 | 要求 | 依据 |
|---|---|---|
| 时长 | 达人合作视频**至少 15s**（图文至少 5 张） | 达人合作规范 5.5.2.4 |
| 菜品讲解 | 至少**口播讲解一道菜品** | 同上 |
| 锚点一致 | 介绍 A 商家不能挂 B 商家 | 5.5.2.2 |
| 拍摄真实性 | 达人**必须真实到店拍摄**，禁止搬运/加工网络素材冒充探店，禁止发布虚假探店内容 | 5.4.2.1 |
| 商家与商品信息 | 店名、地址、商品名、**价格**、菜品、预约方式、使用条件**必须与 POI 详情页一致** | 5.5.2.3 |

> 对代码画视频的直接含义：我们不是探店片，不能声称"到店吃了"。若以达人探店合作名义发布，5.4.2.1 直接不成立；作为普通带货内容发布，则不触发该条，但仍受"信息一致"与"真实性分级"约束。

## 三、价格口径（能写什么、不能写什么）

**可以写**
- 具体团购价，数字与商详当前价一致（例："团购价 12.8"）
- 划线价——**仅当商详有划线价**，且宣传的门市价/指导价与该划线价一致
- 有门槛的价格，只要同时说清门槛（新客价/儿童价/次卡均价/秒杀时段/券后条件）

**不能写**
- 模糊价："100 出头""一百多一点儿""不到一杯奶茶钱""人均不到一百""几十元吃大餐"
- 券后价当宣传价（不同用户券不同，必须讲套餐本身团购价）
- 无划线价却宣传"原价/门市价/日常价 X"
- 划线价无依据或明显虚高（平台 2026-06 起专项治理，售价/划线价低于 1 折属高风险）
- 多件起拍不明说价格含义（"9.9" 实际是 9.9 代 14.9 代金券）
- 价格低于团购价引流
- 馈赠商品标价（赠品不得出现价格）

**价格变了会怎样**：商家改价导致视频价与商详不符，平台处置该条视频（限流/不推荐），一般**不扣达人信用分**；但重复违规会升级处置。

## 四、展示方式（这条最容易翻车）

平台明确要求：**基础价格和限制条件同字号、同色、同位置，清晰无遮挡**；用极小字号、极浅颜色、角落位置、被元素遮挡 = "制造视觉盲点"，属违规。

短视频合规展示三种任选其一：
1. 使用规则/加价规则放**左上角**，字号清晰可见、**不小于昵称字号**、全程展示；
2. 放商详截图并突出关键部分、全程展示；
3. 关键使用规则写在**标题**里。

> 反例：把"优惠/低价"放大高亮，把"加价/限制"缩小淡化——这是最典型的判罚场景。

## 五、禁词与禁手法（内容侧）

- 绝对化用语："国家级""最高级""最佳""第一""天花板""全网最低价""TOP1"
- 稀缺/紧迫："最后一天""限量抢购""秒杀""倒计时""即将下架""马上涨价"
- 截图类：销量截图、评价截图、店铺评分、评论区截图、团购页面截图轮播
- 价格玩法：剧场砍价、家庭矛盾卖惨、计算器暗示优惠、0 元下单/免费下单
- 诱导：引导私下交易、站外核销、诱导互动换优惠
- 虚假体验：编造"我到店吃过/排队两小时"（AIGC 明令禁止生成虚假体验过程）

## 六、AIGC 专项（《抖音生活服务 AIGC 创作规范》）

- **必须主动声明内容含 AI 生成**；不标识会被平台补标并可能判违规。
- 禁 AI 虚构**商品、门店、服务**等核心营销信息；禁夸大**分量、规格、流程、效果**；禁承诺无法兑现的服务。
- 餐饮类目：**不得用 AI 生成不存在的餐品与套餐内容**、不得夸大菜品分量、不得用 AI 生成的虚假环境替代实际就餐环境。
- 违规处置：警告、限流、经营组件自见、内容自见、扣信用分、限制商品推广/发布。2026 Q1 已处置 80 万条 AIGC 违规带货内容。

> 对代码画视频的含义：我们**不画写实餐品**（只画价签、份量格、规格），天然避开了"AI 生成不存在的餐品"这条最大红线；但**份量示意图不能画得比实际多**，门头牌必须用真实门店名，不能画"想象中的店内环境"。

## 七、质量分级：为什么"纯文字海报风"会被压

《生活服务营销内容质量分级体系》负向标准里，这几条与代码画视频高度相关：

| 负向标准 | 判定描述 | 我们的风险 |
|---|---|---|
| **大字报** | 后期文字占比过大、持续时间过长，遮挡内容或影响消费体验 | 高：整片以大字为主 |
| **图文小广告** | 观感像易拉宝/单图海报/少量图片轮播/宣传扉页/商详截图 | 中高：静态版式感强 |
| **素材拼接** | 多个无真人出镜片段拼凑的店铺/商品宣传，无法判断作者是否到店 | 中：无真人无实拍 |
| **云剪辑** | 未实际探店，用他人素材加工发布 | 低（我们自制，但需能自证原创） |
| **生硬带货** | 时长短、只有基础营销信息、无增量决策信息 | 中：15s 只讲价格与规格 |
| **同质化话术** | 高频套路句式（"老板疯了""只卖1天"…） | 低：槽位引擎已禁 |

优质内容要求"真实拍摄 + 真人交互"，纯 AIGC 片在"展现真实"维度拿不到分，**这是结构性上限，不是靠改画面能解决的**。

## 八、给 daihuo 管线的落地修改（按优先级）

**P0 样片立刻要改的 3 处**
1. `价格以商详页为准` 现在 20px 灰字居中——**属小字弱化**。改为：与价格同区、字号 ≥ 昵称字号（建议 34–40px）、同色系、全程展示；或直接写进标题。
2. `门店可直接用团购` 是未经核实的可用性断言——改为商详可证的表述（如"到店核销，具体见商详"），或删除。
3. 首帧到价格段文字占比过高（大字报风险）——用"价签 + 份量格 + 门店牌"三件套把纯文字面积压下来，同一信息用图形承载。

**管线层面的 5 条硬规则（写进生成器，不靠人盯）**
4. 数字白名单升级为**双向校验**：视频里出现的每个数字，必须能在 `cards.json` 的 `price/items/spec/stores_count` 找到；找不到就拒绝出片。
5. `orig_price` 为空时**禁止**任何"原价/门市价/省 X 元/打 X 折"字样的生成（现有降级只做到不出划线价，还要顺带禁文案）。
6. 限制条件槽位**强制与价格同屏同字号**：`usage`（配送/预约/时段/不可用日期）必须有一条进入价格场景，字号不低于价格的 1/4，位置固定在价格下方 80px 内。
7. 禁词表补三类：绝对化（最/第一/天花板/全网最低）、稀缺（最后一天/限量/秒杀/倒计时）、价格模糊（出头/不到/一杯奶茶钱/人均不到）。
8. 出片自动生成 `compliance.json`：数字校验结果、禁词命中、限价一致性、AIGC 声明位、标签待勾选项——任一不通过 exit 1，与 `_qa.json` 同级别门禁。

**发布策略建议（需大宝拍板）**
- 方案 A 纯代码片独立发：合规能过，但真实性维度低，限流概率高，不宜作主力。
- 方案 B 代码片 + 真实门店实拍混编（**推荐**）：实拍承担"真实性"，代码承担"价格/规格解释"，规避"素材拼接"需作者真人出镜或口播。
- 方案 C 代码片只做钩子/尾卡叠在实拍成片上（最稳，复用现有 `hook_overlay_stock.js`）。
